# 插件系统实现与 Release 验证

2026-11-12，Nanobug V2 独立工作区 `codex/plugin-p0`，基线 `d1cadbf`。工作区产物包括编辑器和同目录的插件运行程序。对应操作见 [SDK 示例](../../plugins/sdk/README.md) 和 [分阶段验收清单](../插件系统分阶段验收.md)。

## 已走通的验证

| 范围 | 用例 |
| --- | --- |
| 安装与版本 | 真实 ZIP 权限确认，名称与 ID 的组合身份，版本和实验能力拒绝原因，安装索引发布失败后保住上一版，损坏的编译缓存按需重建，缓存目录不可用时仍能安装并执行 WASM |
| 激活与恢复 | 项目文件创建触发规则自动重算，两个项目共用一个 WASM 进程，最后一个项目关闭后退出。结束实际运行进程后恢复已确认草稿。三次自动恢复用尽后进入暂停 |
| 内存保护 | 在同一进程打开八个项目，超额后请求清理编译模块缓存，持续超额时暂停。初始预算为单运行进程 384 MiB 私有提交，宿主已提交的绘图资源合计 160 MiB。外部工具有独立计量和暂停路径 |
| 规则与配置 | 并行执行规则，区分 JS 计算超限与等待超时，Windows 文件占用后的有限重试，12 MiB 未知扩展名文件的跨块查询和二进制分段读取。Apply 前后两个中断点均恢复对应磁盘状态，两份配置和草稿分别保留 |
| 自绘与网格 | 路径端点、转角和填充规则与原生 GPUI 生成的顶点一致。位图透明度、随包字体和 Canvas 回调已接入。两个真实示例 ZIP 均在 Windows 使用微软拼音，覆盖搜索和 ZIP 路径的预编辑取消、数字切页、中文选词、Emoji 前插入、选区替换和草稿保存 |
| 编辑与解析 | UTF-8 编辑组检查及单组撤销，未打开文件的版本核对和后续保存冲突保护。交互模块自动刷新使用版本化增量，缺少基准时补发正文。真实 WASM 往返覆盖中文、组合字符、Emoji、Tab、CRLF 和同路径重开。公共解析按文档版本复用，支持 Vue 嵌入语言，解析进程退出后编辑器继续保存 |
| 工具 | 真实 HTTPS 下载并校验 ZIP，解包缓存可复用。后台工具独立恢复并同步最新未保存正文。保持 Rust 项目打开，反复关闭和重开 Vue 项目三次，每次释放其独占实例和真实工具进程。一次工具执行中断后保持待确认，重开并重新授权也没有重跑 |
| 设置与凭据 | 项目覆盖、Apply 和保存失败处理，本机设置可单独清理。升级后可读同类型的旧键，类型不匹配的旧值保留且不阻塞无关修改。Windows 凭据库按配置环境隔离。新凭据的磁盘引用发布失败时保留旧凭据 |
| 开发、更新与清理 | 示例由 Rust SDK 实际编译。开发构建失败保留当前版本。更新等待已确认写入，可暂缓，候选启动失败恢复上一版。文件和工具结果可跨重开查看，未知结果保留待确认。包和工具缓存保留在用引用 |

最终集成构建通过 208 项常规测试、Clippy 和 Release 打包。另执行 DirectX 画面对照、Windows 凭据库两项用例、真实解析进程退出、开发构建失败、已安装 SDK、旧版 ZIP 和真实 HTTPS 用例。两个示例的原生记录在 `test-output/plugin-optimized-canvas/ui-smoke.jsonl` 和 `test-output/plugin-optimized-grid/ui-smoke.jsonl`，包含快捷键帮助、过滤确认及 q 和 Esc 返回列表。早期前台尝试有窗口焦点失效，成功样本是在单独激活测试窗口后采集。

新运行程序直接加载了较早的 SDK 示例 ZIP，成功运行其中原始 `1.0` WASM 并准备 Canvas 画面。较早的 WASM SHA-256 为 `45a8fbe4d1542963133a29f95a5b2872812c9dddf02fd901f96f40656f6dd5fe`，压缩包保存在 `test-output/plugin-release-final/workspace-panel.zip`。

Windows DirectX 在 150% 系统缩放下对同一个场景分别绘制原生 GPUI 和真实 SDK 插件。121,500 个像素中有 121,491 个完全一致，九个变换虚线路径边缘像素的通道值相差 1。场景覆盖裁剪、偏移、顺序、渐变、斜纹、棋盘、阴影、描边、文字装饰和位图透明度。测试只在 Windows 测试构建启用 GPUI 读取像素的功能。[画面对照和复现命令](2026-11-12-plugin-p0-gpui.md)

两次 Windows 草稿异常退出测试均连续输入 45 次，输入期间观察到多次持久化。直接终止测试编辑器后，磁盘各保留前 43 次确认输入，最早一条未落盘的输入距进程退出分别为 136.010 ms 和 126.722 ms。磁盘正常时的原始样本分别在 `test-output/plugin-draft-crash/summary-draft-crash.json` 和 `test-output/plugin-optimized-draft/summary-draft-crash.json`。

## Windows 热启动

使用 Windows 11 专业版 26200、Ryzen 9 9950X3D、约 61.6 GiB 可见内存、RTX 5080、NVMe SSD 和平衡电源模式。显示模式为 3840×2160、120 Hz。本轮记录了正文模型更新，屏幕呈现延迟和缩放矩阵另行验收。测试保留机器当时的后台负载。

各项目使用固定的短 README 和小型插件。50 个包实际安装并执行 JS 条件，命中的 10 个模块执行 WASM 打开事件。正文就绪从 Windows 进程创建计到首帧后的核心就绪事件，随后测试向指定编辑器窗口提交字符，等待正文修订改变并撤销。输入延迟口径为 Windows 消息提交到正文更新。

## 2026-11-12 首轮未覆盖范围

- Windows 真实系统冷启动、含索引和绘图压力的长时间输入和屏幕呈现延迟，以及不同工作区规模的资源归因。
- Windows 组合场景已实测。原生 GPUI 与 SDK 的完整对照还需覆盖 SVG、Emoji、动画帧、字体组合、更多缩放和全部光标特效。Apple NV12 桥接已经过 ARM64 目标类型检查，完整构建受 GPUI Metal 着色器产物限制。Apple 实际画面及 Linux 桌面全流程仍待验证。
- 文档增量用于交互 WASM 模块的自动正文刷新。显式命令与解析仍发送完整快照。未保存缓冲区与磁盘文件混用时的原生编辑回归、跨类型设置迁移及其他平台凭据仍待验收。
- 多操作同时故障、长时间资源回收、完整历史宿主与插件组合仍待测试。项目配置替换前已复查原内容。外部程序如果不使用同一锁，最后检查到替换之间仍可能发生竞争。
