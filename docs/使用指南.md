# Nanobug V2 使用指南

Rust 原生字符网格编辑器。GPUI 负责窗口和绘制，`src/vim/` 实现编辑命令，Nanobug 管理项目、文件和原生输入法。

无参启动进入启动页。打开项目后，左侧显示文件管理器，右侧显示编辑区。全窗口共享平滑光标，逻辑焦点立即切换，输入法候选位置跟随逻辑输入点。背景采用 **84% 不透明度**（约 16% 透明），文字独立保持不透明。Windows 使用系统模糊材质，其他平台的材质表现尚未验收。

内部面板沿用 Glass Editor Demo 的网格样式。实线和虚线边框按网格定位，由 GPUI 路径绘制，标题嵌在上边线，焦点通过边框颜色标记。顶部项目栏用 `|` 分隔项目，以薄荷绿色块标记当前项目。两侧的 `←2` 或 `4→` 表示被隐藏的项目数量。单击顶部标签可切换。Windows 上可按住标签或项目栏空白处拖动窗口。底部状态栏使用斜角色块，左侧显示模式与操作反馈，右侧显示编码、光标所在行的进度和行列位置。命令与搜索输入使用左侧。

## 运行

从源码运行时，在项目根目录执行 `cargo run --locked`，也可运行 `Start-Nanobug.ps1`。

在依赖已缓存时运行 `Build.ps1`，可生成 `dist/Nanobug.exe` 和 `dist/启动 Nanobug.cmd`。双击启动脚本或直接运行 EXE 会进入启动页。传入目录或文件路径可直接打开项目。

```powershell
cargo run --locked -- .
```

左侧读取真实文件系统，右侧初始打开项目 README.md；没有 README 时显示空白缓冲区。双击文件或在管理器按 Enter 打开，先前文件的未保存内容会保留在内存，再次打开可恢复。

### 插件和数据目录

按 `Space`、`Shift+P` 打开插件管理，按 `3` 切到「本地 ZIP」，再按 `Enter` 打开文件选择器。它只列出目录和 ZIP 文件。按 `Enter` 进入目录或选中 ZIP，选中后查看清单并确认安装。按 `Esc` 可退出选择器并返回插件管理。

下次打开「本地 ZIP」会回到上次选中文件的目录，重启后也会保留。目录不可用时，从当前项目或默认位置开始。普通文件浏览器有独立的定位记录。

发布版把安装清单和插件文件写入 `Nanobug.exe` 同级的 `plugins/`，把插件设置和草稿写入 `data/plugins/`，把最近项目写入 `data/recent-projects.json`。首次启动时会从旧的用户目录导入这些数据，并保留旧文件供回退。Windows 上的旧目录为 `%LOCALAPPDATA%\Nanobug`。请将发布版解压到可写目录。

最近项目使用绝对路径。迁移到另一台电脑后，可以重新打开路径有变化的项目。API Key 等密码仍由系统凭据库保存，复制发布目录后需要在新的系统账户中重新填写。

从源码执行 `cargo run --locked` 时，默认插件目录随调试产物放在 `target/debug/plugins/`，最近项目保存在同级的 `target/debug/data/recent-projects.json`。调试插件 SDK 时，按 SDK 的命令使用独立的 `test-output/dev-profile`，可以保留安装和草稿，也能调试本地构建。 [插件 SDK](../plugins/sdk/README.md)

### 启动页

启动页是独立的非编辑标签。可按菜单右侧的快捷键、点击菜单，或用 `j/k` 和方向键选中后按 `Enter`。

| 按键 | 操作 |
| --- | --- |
| `o` | 通过 Open a project / file 打开内置文件选择器，可选择项目目录或文件 |
| `p` | 查看最近项目，左栏筛选和选择，右栏预览所选项目的顶层目录 |
| `c` | 查看全局配置的实现状态 |
| `X`（`Shift+x`） | 关闭本启动页，返回最近使用的标签。只有这一页时退出编辑器 |

打开项目选择器后可直接输入项目目录名的任意一段，筛选忽略大小写。按 `Esc` 保留筛选结果并进入列表导航，用 `j/k` 向下或向上移动，可加数字跳过多行，例如 `5j` 向下移动 5 行。按 `/` 或点击筛选框可继续筛选，在列表导航时按 `Esc` 返回菜单。`↑/↓` 和 `Ctrl+j/k` 在两种模式下都可以移动选中项。单击可预览，按 `Enter` 或双击可打开。

在列表导航时，按 `d` 确认是否移除选中的最近项目记录。按 `Y` 或点击「是」移除，按 `N`、`Esc` 或点击「否」取消。移除操作只更新最近项目列表。

从最近项目窗口或内置文件选择器打开目录时，项目会接替当前启动页标签。已打开的项目会移到该标签位置，并保留缓冲区和窗格状态。最近项目记录跨重启保留。

启动菜单和项目选择器共用动态光标。选项目时光标在选中行首，输入筛选词时切到筛选框末尾。可用 `F6` 或 `Shift+F6` 切换光标预设。

### 文件选择器

启动页用 `o` 打开，普通模式用 `<leader>E` 打开（先按 `Space`，再按 `Shift+e`）。项目标签定位到项目的父目录并选中当前项目，单文件标签定位到文件所在目录并选中当前文件。窗口标题显示当前路径，三栏依次显示父目录、当前目录和预览。按 `<leader>?` 查看选择器帮助。鼠标移到右上角时会显示帮助和关闭按钮。按 `h/l` 返回或进入目录，`j/k` 移动。列表中按 `<leader>q` 返回打开选择器前的页面。

选中目录按 `Enter` 打开项目。选中文本文件按 `Enter` 时，如果某个已打开的目录项目里已有该文件的缓冲区，就切到对应项目、Tabpage 和编辑窗口。其他文本文件以文件名作为顶层标签打开。独立文件标签只显示编辑区。操作消息显示在右上角，2 秒后自动消失。警告和报错使用圆角实线框，图标和标题在上边线居中。警告用橘黄色，报错用红色。

按 `f` 在栏标题下方居中打开筛选框，实时筛选当前目录。按 `Enter` 收起输入框并保留筛选词，中栏标题会显示该词，例如 `[Filter: notes]`。筛选时按 `Esc` 清除筛选并恢复完整列表，再按一次退出选择器。输入框中的空格和 `x` 按普通文字处理。`g` 显示跳转键，`g Space` 输入路径。

按 `/` 输入名称片段，当前列表中的匹配项会高亮。按 `Enter` 应用搜索并定位到当前行起的第一个匹配项，再用 `n` / `N` 循环跳到下一个或上一个匹配项。浏览时按 `Esc` 清除搜索高亮。如果同时用了 `f` 筛选，再按一次清除筛选。

用 `s` 标记，`y` 或 `c` 复制，`x` 剪切，进入目标目录后用 `v` 或 `p` 粘贴。`a` 新建，名称以 `/` 结尾时创建目录。`r` 改名，`d` 移到回收站，`D` 永久删除。删除需要确认。

三栏列表中的缩略预览可用 `J/K` 滚动。选中文件按 `l` 或 `→` 进入两栏预览，左侧列出文件所在目录，右侧显示只读内容。文本使用编辑器的 Vim 移动、滚动、搜索、选区、标记和宏，`y` 复制到剪贴板。普通模式按 `Esc` 返回三栏，搜索和可视模式先回到普通模式。

底部按 `操作名: 按键 | 操作名: 按键` 显示当前快捷键。非文本预览显示已注册提供方的操作。没有匹配提供方时，可用 `Shift+o` 交给系统默认程序，Windows 上对 `.exe` 执行的是运行程序。

### 界面语言

在启动页、编辑区普通模式或文件管理器中，用 `<leader>L` 打开 `language` 弹层，实际按键是 `Space`、`Shift+l`。用 `↑/↓` 或 `k/j` 移动，按 `Enter` 或点击 `apply` 应用，也可直接点击语言。按 `Esc`、点击 `close` 或点击弹层外取消。

确认后立即切换所有项目的界面语言，并保存到编辑器 EXE 同级的 `data/settings.toml`。发布版使用 `dist/data/settings.toml`，源码调试版使用 `target/debug/data/settings.toml`。

```toml
[ui]
language = "zh-CN"
```

启动时优先使用有效的 `NANOBUG_LANG`，其次读取已保存的 `ui.language`，默认使用英文。环境变量只影响启动时的语言。通过语言弹层确认选择时会保存新的偏好。

```powershell
$env:NANOBUG_LANG = 'zh-CN'
.\Start-Nanobug.ps1
```

将 `NANOBUG_LANG` 设为 `en` 可在本次启动使用英文。移除变量后重新启动，会沿用已保存的偏好。英文和简体中文的 TOML 翻译资源位于 `assets/i18n/`，随可执行文件内嵌。

### 界面外观

在编辑区普通模式输入命令后按 Enter。外观对这次运行的所有项目生效，插件使用编辑器默认样式时会同步刷新；插件指定的颜色或字体保持原样。

| 命令 | 效果 |
| --- | --- |
| `:theme dark` / `:theme light` / `:theme system` | 深色、浅色或跟随系统 |
| `:font rec` / `:font maple` | 使用内置的 Rec Mono Casual 或 Maple Mono NL CN |
| `:fontsize 18` | 设置基础字号，范围 12–24 |
| `:zoom 125%` | 设置界面缩放，范围 75%–150%，独立于显示器的 DPI |

命令立即生效，并将对应选项保存到 EXE 同级的 `data/settings.toml`。下次启动会恢复这些设置。`zoom` 在文件中按百分比填写，例如 `125` 表示 125%。将命令参数写成 `default` 可恢复并保存该选项的默认值。

```toml
[ui]
language = "zh-CN"
theme = "light"
font = "maple"
font_size = 18
zoom = 125
```

深色和浅色配色分别保存在 EXE 同级的 `data/theme-dark.toml` 和 `data/theme-light.toml`。两个文件独立加载，每个颜色参数旁都有中文注释。升级后首次启动时，Nanobug 会用旧 `data/theme.json` 中的色值生成尚未创建的 TOML。已有的 TOML 优先使用，旧 JSON 保留为备份。如果文件格式或色值无效，受影响的主题本次使用内置配色，原文件会保留供修正。色值保持对应字段的 `#RRGGBB` 或 `#RRGGBBAA` 格式，后者末两位表示不透明度。保存修改后重启 Nanobug 即可生效。 [深色默认配色](../assets/theme-dark.toml) · [浅色默认配色](../assets/theme-light.toml)

在对应的主题文件中，可以为组件和子区域设置单独的配色。颜色按字段读取，优先用子区域的值，其次用父组件、文件顶层和内置默认值。

| 配置表 | 常用颜色 |
| --- | --- |
| `[components.editor]` | 编辑区底色 `background`、代码文字 `text`、选区底色 `selection` |
| `[components.editor.gutter]` | 行号栏底色 `background`、普通行号 `muted`、当前行号 `gold` |
| `[components.explorer]` | 文件管理器底色 `background`、边框强调色 `accent` |
| `[components.explorer.tree]` | 文件树底色 `background`、选中行底色 `selection`、层级连接线 `tree_guide` |
| `[components.footer]` | 状态栏底色 `background`、文字 `text`、各徽章的 `footer_*` 底色 |

例如仅填写下面这两行，就可以单独改变行号栏底色。

```toml
[components.editor.gutter]
background = "#162334ff" # 仅改变行号栏底色
```

## 基础操作

按下 `z`、`Ctrl+w` 或 `<leader>` 等序列前缀后稍停，右下角的「按键序列提示」（Key Sequence Hint）会列出可用的后续键。弹层顶边显示当前前缀及分组，例如 `z[+折叠]` 或 `z[+fold]`。

`<leader>` 默认使用空格键，也可按反斜杠，适用于启动页、编辑区普通模式和 Explorer。带 `+` 的条目进入子分组，提示中用 `→` 依次连接空格键图标和已输入的各级分组键。`Backspace` 或底部的 `back` 返回上一级，在首层回退会关闭提示。`Esc` 或底部的 `close` 取消整个序列。

| 区域 | 操作 |
| --- | --- |
| 顶层标签切换 | `Alt+h` 或 `Alt+k` 切到上一个标签，`Alt+l` 或 `Alt+j` 切到下一个。回到项目时继续使用上次选中的 Tabpage |
| 标签排序 | `Ctrl+Alt+h/k` 向左移动当前标签，`Ctrl+Alt+l/j` 向右移动。`Ctrl+Alt+Home/End` 移到最前或最后 |
| 启动页和标签 | `<leader>pa` 新建启动页标签。项目或独立文件标签中按 `<leader>x` 关闭当前标签。按 `<leader>X` 关闭全部标签并回到启动页 |
| 窗格切换与关闭 | 普通模式下，`Ctrl+h/j/k/l` 按当前布局选择左、下、上、右的窗格。朝已隐藏的编辑区移动可恢复它。非文本输入时，`<leader>q` 关闭当前窗格。编辑区也可按 `Alt+Esc`，Explorer 可点击右上角的叉号 |
| 切换 Explorer 显隐 | 普通模式下按 `<leader>e`（先按 `Space`，再按 `e`）。显示时聚焦 Explorer，隐藏时聚焦编辑区 |
| 快捷键帮助 | 普通模式下按 `<leader>?`（默认先按 `Space`，再按 `?`），也可点击 Explorer 右上角的 `?`。点击标题可切换帮助标签，也可用 `Ctrl+h` 或 `Ctrl+←` 查看区域快捷键，用 `Ctrl+l` 或 `Ctrl+→` 查看全局快捷键。按 `Esc` 关闭帮助窗口 |
| 文件管理器 | `j k` 移动，`h` 折叠，`l` 或 Enter 打开文件或切换目录，`gg G` 跳到首末项，`zz zt zb` 定位视口。鼠标单击选中，双击激活，F5 刷新 |
| 管理器文件操作 | `s` 标记多项，`c x` 复制或剪切，`v` 粘贴，`z Z` 撤销或重做粘贴 |
| 分栏宽度 | 鼠标拖动垂直分隔线 |
| 指针编辑 | 点击定位，拖动进入字符选择，滚轮纵向滚动，Shift+滚轮横向滚动编辑区 |
| 光标动效 | F6 切换预设，Shift+F6 反向切换，F7 重载项目光标配置 |
| 插入模式 | `i a I A o O`，Esc / Ctrl+[ 回到普通模式 |
| 插入编辑 | 方向键、Backspace、Delete、Enter、Tab、Ctrl+w、Ctrl+u，Ctrl+v 粘贴系统剪贴板 |
| 光标移动 | `h j k l w b e 0 ^ $ gg G`，支持数字次数和 `3G` |
| 删除/修改 | `x s dd dw de d$ D cw cc C`，支持 `2dd`、`d2w` 等 |
| 复制/粘贴 | `yy` 复制整行，`Y` 复制到行尾，`"ayy` 复制到寄存器 a，`p/P` 粘贴 |
| 选择 | `v` 选字符，`V` 选行，`Ctrl+v` 选块，`Esc` 取消 |
| 撤销/重做 | `u` / Ctrl+r，一次插入会话为一个撤销单元 |
| 行操作 | `J` 合并下一行 |
| 搜索与替换 | `/模式` 向前搜索，`?模式` 向后搜索，`n/N` 同向或反向重复。用 `:%s/旧/新/g` 替换全文 |
| 文本对象与重复 | `ciw` 修改当前词，`.` 重复修改，`qa … q` 录制宏，`@a` 执行宏 |
| 保存 | `:w`、`:w 文件名`、Ctrl+s |
| 打开 | `:e 文件名` 在当前项目打开文件，`:e 目录` 打开或切换到该项目。支持绝对路径和相对项目根目录的路径 |
| 退出 | `:qa`、`:q`、`:q!`、`:wq`、`:x` |

编辑区的快捷键页显示六排键盘，包括功能键、导航键和方向键。点击键帽或单按对应按键，底部虚线框会显示操作和示例。单按 `Ctrl`、`Alt` 或 `Shift` 并完全松开后切换组合视图，再单按并松开即可取消，也可点击任一侧对应的修饰键帽。分别单按并松开 `Ctrl` 和 `Alt` 可查看两者搭配的组合。要查看 `Ctrl+s` 的说明，先单按并松开 `Ctrl`，再按 `s`。直接按 `Ctrl+s` 会执行保存。进入编辑模式、等待后续输入或切换工作区标签的组合键在退出帮助后执行。

编辑时，普通模式按 `Ins` 进入插入模式，输入中再按 `Ins` 可在插入和替换模式之间切换。查看快捷键时单按 `Ins` 可打开它的示例。

灰色键不能单独选中。数字 `1` 到 `9` 用作命令的次数或行号，组合用法写在对应键的说明里。例如查看 `j` 会显示 `2 j` 向下移动两行。编辑区的快捷键帮助暂停 Leader，`Space` 键帽用斜纹标记为禁用。浏览时单按 `Esc` 关闭弹层。

在帮助列表中，`j/k` 或上下方向键移动选中行，也可用鼠标点击。`5j` 向下移动 5 行，`5k` 向上移动 5 行。`gg`、`G`、`3G` 跳到首行、末行和指定行，`PageUp/PageDown` 移动一页。列表平滑滚动，光标到可滚动边缘的第 4 行时，再移动会带动列表。

按 `/` 用搜索框覆盖列表底部一行，实时按快捷键描述筛选。按 `Enter` 保留筛选并继续浏览，按 `Esc` 取消本次输入，也可点击对应按钮。`n/N` 浏览下一条或上一条匹配。切换区域和全局时保留筛选词，重新打开帮助时从当前窗口的完整列表开始。

Explorer 使用内置的 Material Icon Theme 深色图标。文件按名称或后缀匹配，未知类型使用通用文件图标。目录按名称匹配，并随展开和收起切换图标。[Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme)

`<leader>x` 只检查并关闭当前的项目或独立文件标签。`<leader>q` 关闭标签内最后一个可见窗格时，也走该标签的关闭流程。关闭项目或文件标签后优先选中右侧标签，位于末尾时选中左侧标签。没有其他标签时回到启动页。`<leader>X` 会检查所有标签的未保存文件，确认后关闭全部标签并回到启动页。`:qa` 和关闭原生窗口会检查所有标签的未保存文件并退出编辑器。

确认框中，`Y` 保存当前文件，`N` 在关闭时放弃当前文件的修改，`C` 或 `Esc` 取消关闭。还有多个文件待处理时，`A` 全部保存，`D` 全部放弃。未命名文件保存时会打开另存为窗口，写入失败会停在该文件。取消关闭会保留待放弃的修改，已经写入的文件仍已保存。`:qa!` 放弃所有缓冲区的未保存修改后退出。保存时先写入同目录的临时文件，再替换原文件。

管理器将文件粘贴到当前目录项，或当前文件的父目录。同名目标会阻止粘贴。单按 `z` 等待 350 毫秒后撤销，供 `zz`、`zt`、`zb` 输入第二键。每次粘贴作为一条历史，最多保留 10 条，编辑相关文件会使对应记录失效。

普通模式和选择模式直接接收命令按键，中文输入法不会拦截 `i`、`:`、`hjkl` 等操作；插入、搜索和命令行模式继续使用原生文本输入法。

### 项目会话

每个目录项目在 EXE 同级的 `data/project-sessions/` 保留一份最新会话。重开项目会恢复 Tabpage 的顺序和选中页、各页的分屏与 Explorer 布局、窗格里的文件标签及光标和滚动位置。Markdown 也会恢复编辑或预览模式。指定文件打开项目时，恢复布局后会聚焦指定文件。

编辑器在后台保存界面变化，关闭项目或退出前再保存一次。会话从磁盘重新读取正文，未保存修改仍按关闭确认处理。单个文件找不到或无法读取时跳过该标签，其他布局照常恢复。没有可用会话时打开 README 或空白编辑区。

### 编辑区的文件标签、分屏和 Tabpage

每个编辑窗口都有自己的文件标签。标签显示文件名和类型图标，用 `|` 分隔。单击标签可在该窗口切换文件，聚焦后也可以用 `[b` 和 `]b` 前后切换。空间不足时，`2←` 和 `→3` 分别表示左侧隐藏两个、右侧隐藏三个文件标签。单击计数可跳到相邻的隐藏文件。

聚焦编辑窗口后，按 `Ctrl+w s` 在上方分屏，或按 `Ctrl+w v` 在左侧分屏。也可输入 `:split` 或 `:vsplit`，在命令后加文件名可在新窗口打开指定文件。分屏可以继续拆分。单击编辑窗口或用 `Ctrl+w h/j/k/l` 切换焦点。文件标签、缓冲区、光标、滚动位置与撤销历史由各窗口独立管理。

主窗口右上角的 `1 | 2 | 3` 用来切换当前项目的 Tabpage，与左侧的项目标签同一行。可单击页号，或按 `gt`、`gT`、`g<Tab>` 切到下一页、上一页、上次使用的页。输入 `2gt` 直接到第 2 页。页号较多时，也可以单击溢出计数跳到相邻的隐藏页。

项目只有一页时，主窗口顶栏隐藏页号。在目录项目中，输入 `:tabnew` 可以在新页打开当前文件，也可以用 `:tabnew 文件名` 在新页打开指定文件。按 `Space → Tab` 可打开 Leader 的项目内标签页分组。再按 `Tab` 新建一页，按 `d` 或输入 `:tabclose` 关闭当前页。项目至少保留一页。

每页保留自己的分屏布局、活动窗口和编辑位置。中键点击文件标签可从所属窗口移除文件。关闭含有未保存修改的文件、窗口或 Tabpage 时，编辑器会询问如何处理修改。

同一个文件可在多个窗口独立编辑。如果一个窗口已经保存，另一个窗口再保存与磁盘上不同的内容时，编辑器会保留它的修改并提示文件已变更。

当前 Tabpage 有多个编辑窗口时，`:q` 关闭当前窗口，`:q!` 放弃该窗口的修改并关闭，`:wq` 保存当前文件后关闭窗口。如果保存需要等待插件格式化，在完成前切换项目或 Tabpage 会保留原窗口。只有一个编辑窗口时，这些命令执行退出编辑器的流程。

### Markdown 预览

Markdown 文件在 Tabpage 中首次打开时，默认左侧编辑、右侧预览。在普通模式按 `<leader>m` 打开视图选择。默认 Leader 是空格。再按 `a` 切换到双栏，按 `e` 仅编辑，按 `p` 仅预览。编辑区会保留当前 Tabpage 中每个文件的视图选择。聚焦其他窗口或其他类型文件时，Leader 提示不显示 Markdown 分组。

预览随缓冲区内容更新，包括未保存的编辑。内置解析支持 GitHub 风格的表格、任务列表、删除线、代码块和常用内嵌 HTML。双栏时，任一栏纵向滚动都会带动另一栏按文档内容同步。滚动预览时保留源文中的光标位置。仅预览时用 `j/k`、方向键、`PageUp/PageDown` 或 `gg/G` 浏览。

Markdown 源文内置语法高亮，标题、强调、链接、代码和列表标记使用当前主题的语法颜色。双栏的源文距分隔线一列，预览在分隔线一列之外再留一个中文字宽。编辑区横向滚动时，只有完整落在源文视口内的宽字符才会显示。

预览的正文和代码使用编辑器当前的中英文字体和字号。标题按级别缩放。单击预览中的链接可以跳到文档标题、在编辑器中打开相对路径指向的文本文件，或用系统默认应用打开网页和邮件链接。

支持用 Markdown 图片语法或 HTML `<img>` 显示本地和 HTTP(S) 的 PNG、JPEG、GIF 和 WebP 图片。HTML 图片可以用 `width` 和 `height` 指定尺寸。宽度也支持百分比。只指定一项时，另一项按原图比例计算。图片宽于预览栏时会等比缩小。远程图片在后台加载，等待时显示占位，加载失败后显示替代文字。

HTML 段落或容器的 `align` 和内联 `text-align` 可以对齐其中的文本和图片。例如，`<p align="center"><img src="logo.png"></p>` 会把图片放在预览栏中央。图片也支持通过水平自动外边距对齐。表格支持为各行和单元格指定横向对齐，`display: none` 可以隐藏元素。

## 光标与滚动动效

启动时使用带渐隐残像的“余晖”。F6 可在“流体”“弹性”“余晖”“涟漪”间循环。四种预设使用同一套光标阶段。

在项目根目录编辑 `cursor-effects.toml`，按 F7 应用。优先级从低到高为内置预设、`[stages.<阶段>]` 和 `[presets.<预设>.<阶段>]`。预设键为 `fluid`、`elastic`、`afterglow`、`ripple`。填写 `effects` 会替换该阶段继承的列表，空数组会清空。

| 轨道 | 阶段键 |
| --- | --- |
| 主流程 | `place`、`idle`、`target`、`prepare`、`travel`、`approach`、`arrive`、`settle`、`post_move` |
| 区域滚动 | `scroll_start`、`scroll_follow`、`scroll_settle`、`scroll_end` |
| 显隐 | `show`、`hide` |

效果项的 `kind` 可选 `droplet`、`stretch`、`rebound`、`afterimage`、`ripple`、`breath`、`blink`、`scale`、`glow`、`fade`、`scroll_drag`。通过 `strength` 调强度，通过 `delay_ms`、`duration_ms`、`repeat_ms` 和 `count` 调播放节奏。阶段内的重复效果在离开时停止，瞬时事件的重复需要指定次数。有限单次效果可用 `finish = true` 让它在阶段退出后播完。未指定时长的视觉脉冲为 300ms，形状和运动修饰默认随阶段保持。`afterimage` 的时长同时决定残像衰减长度，默认每个残像 180ms。

`prepare.duration_ms` 和 `prepare.insert_ms` 分别设置块光标和细插入光标的准备时间，`post_move.duration_ms` 设置驻留时间。可用 `response_ms` 调行进、收束或滚动拖尾的响应时间。`ripple` 支持 `target = "cursor"`、`"nearby_text"` 或 `"both"`，可通过 `radius_px` 和 `text_offset_px` 调波及范围和字形位移。模板包含可直接启用的组合。

管理器和编辑区都采用连续平滑滚动，停稳时对齐整行或整列。编辑区光标向左右边缘移动时，正文从第 8 个显示列附近开始跟随，行号栏保持横向固定。正文裁剪在窗格边框内。光标头部随所属正文平移，滚动速度驱动主轮廓的拖尾。静止延时和脉冲间隔使用定时唤醒，持续形变时逐帧刷新。

运行 `cargo run --offline --example animation_trace` 可导出实际动效模型的比较数据。可选用 Pillow 执行 `python tools/render_cursor_preview.py test-output/cursor-effects.csv test-output/cursor-effects.gif` 生成预览；Python/Pillow 只用于离线制品，不是编辑器运行依赖。

## 当前范围

Nanobug 用 Rust 实现字符键盘帮助中的 Neovim 风格按键。搜索和替换支持常见 Vim 模式写法，包括 `\(`、`\|`、`\<`、`\>` 和替换分组。跳转历史和标记按缓冲区保留。完整的 Ex、Vimscript、Neovim 插件和正则语法不在当前兼容范围内。

目前支持 UTF-8 文本，打开大小上限为 16 MiB，保留已有 BOM、LF/CRLF 与 Tab。编辑历史由文档保存。输入法接入了本地预编辑与提交，仍需覆盖各输入法的人工验收。

基础框架未加入插件系统、语言服务或语法高亮。当前固定 GPUI 0.3.10，本机 Windows 是已构建和交互验证的平台。

## 语言插件

语言插件分别安装。Windows 可以在插件管理面板的「本地 ZIP」中选择 `dist/language-plugins` 下的包。每个源码目录与 `nanobug` 和 `nanobug-rust-plugin` 同级，批量构建入口为同级的 `nanobug-language-plugins/Build.ps1`。

在已启用语言插件的文件中输入标识符或触发字符，候选会在光标旁自动显示。也可在插入模式按 `Ctrl+x Ctrl+o` 立即请求。用 `↑`、`↓` 或 `Ctrl+p`、`Ctrl+n` 选择候选，`Enter`、`Tab` 或 `Ctrl+y` 确认，`Ctrl+e` 关闭候选，`Esc` 关闭并返回普通模式。菜单关闭后，`Enter` 和 `Tab` 继续执行编辑操作。

补全按字符顺序做不区分大小写的模糊匹配，并在候选名称中标出命中的字符。输入 `pbf` 可以匹配 `PathBuf`。

语言插件的扫描排除配置按插件 ID 保存在项目根目录的 `.nb/plugin-setting/<插件 ID>.toml`。例如 Rust 使用 `rust.toml`，JSX／TSX 使用 `jsx-tsx.toml`。写入 `excludeDirs = ["test-output"]` 可追加项目相对目录。Nanobug 合并用户目录和插件 JS 返回的目录，校验路径并去重。修改 TOML 后重新打开项目即可生效。已有 `.nb/rust-analyzer.json` 的项目可以将名单迁入 TOML，尚未创建 TOML 时仍可读取旧的 JSON。

Nanobug 按合并名单过滤语言服务器的文档同步、补全和定义请求以及返回的定义位置，并映射到服务器支持的原生设置。TypeScript、Vue、Svelte 和 Astro 的排除设置作用于自动导入，编译器文件范围仍由各项目的 TypeScript 配置负责。SQLFluff 按已同步的文档检查语法，H2 的 sqls 则从连接的数据库读取结构。插件自动排除项随项目标记决定，例如 Rust 的 Cargo fuzz 崩溃样本和 SQL 插件识别到的 dbt 生成目录。

已安装并启用的语言插件会用各自的 JS 规则识别项目。例如 Rust 检查 `Cargo.toml`，Go 检查 `go.mod` 或 `go.work`，TypeScript 检查 `tsconfig.json` 等项目标记。项目已允许工具执行时，匹配的插件会在打开项目时请求启动语言服务器。独立文件仍按其扩展名启用语言功能。

语言服务器在后台索引，期间可以继续编辑和切换文件。底栏显示启动中、索引中、已就绪或启动失败。补全和定义跳转在服务器能够回答请求时即可使用。启动失败原因可在对应插件的「模块」页查看。

普通模式下，按 `K` 在光标旁查看语言服务器提供的签名、类型和文档注释。文档默认按 Markdown 渲染，支持标题、列表、强调和代码块。网页和邮件链接可以点击，图片显示替代文字。弹层打开时，`PageUp` 和 `PageDown` 每次平滑滚动 4 行。鼠标悬停在弹层内时，滚轮也可平滑滚动正文。滚到首尾时编辑区保持原位。按 `Esc` 关闭后，这两个键恢复编辑区翻页。该功能已接入 Rust 插件。`gd` 或 `Ctrl+]` 跳转定义，`gO` 打开文档大纲，`[d`、`]d` 跳到上一个或下一个诊断，`[D`、`]D` 跳到第一个或最后一个诊断，`Ctrl+w d` 显示光标处的诊断。

跳到项目外已索引的 Rust 依赖或标准库后，`gd` 和 `K` 仍可使用原项目的 `rust-analyzer`。这些查询使用磁盘上的索引，要求编辑器内容与磁盘文件一致。

普通 `.sql` 文件每次使用一个方言插件。`:sqldialect mysql` 保存项目方言，并允许对应的插件按项目预启动。`:sqldialect! mysql` 仅覆盖当前缓冲区。将 ID 改为 `auto` 可恢复按打开的 SQL 文件选择和启动。

`EditorWindow` 的缓冲区集合、活动索引、寄存器和输入状态保持私有，调用方通过只读查询、编辑操作和版本校验后的批量事务完成工作。`ManagerWindow` 同样封装目录树、选择、滚动、文件操作历史和延迟按键状态。跨窗口协调通过操作接口进行，例如编辑文档后使文件历史失效、移动文件后同步缓冲区路径。原生输入法仍由 `workspace/ime.rs` 统一按焦点和模式切换，各窗口保留自身的预编辑或文本状态。

插件管理窗口拥有浏览状态、行构造、配置比较和绘制几何；插件窗口拥有草稿、选择、原生文本布局和 Canvas 绘制。它们接收只读会话快照及必要的展示数据，不依赖 `Workspace`。`workspace/plugins` 负责会话消息、编辑器操作、原生事件和窗口之间的连接。插件引擎保留顺序执行的监管循环，安装、开发构建、运行实例和请求各有独立状态，外部继续通过 `Session` 和发布的 `View` 交互。

依赖方向为 `app → grid::workspace → grid::windows + grid::render`。窗口使用 `vim`、`document`、`filesystem`、插件会话模型和通用 `ui` 能力。`vim` 返回保存、打开、关闭等动作，由工作区执行；它不依赖 GPUI 或网格窗口。`document` 不依赖 Vim，`filesystem` 不依赖任何窗口，文件选择器和文件管理器分别管理自己的交互状态并复用目录读取与文件搬移。通用 `ui` 和 `grid::render` 不反向依赖具体窗口或工作区。

仓库根目录的 `plugins/sdk`、`plugins/runtime` 是独立 Cargo crate，分别承载插件开发接口及共享协议、隔离运行时；`src/plugins` 是编辑器宿主侧实现。`experiments/plugin-probe` 及其 `wire` crate 保留实验探针用途。保持这些边界，不把原生窗口状态放入插件引擎，也不让共用文件操作承担某个窗口的导航和提示逻辑。

新增网格窗口放在 `grid/windows/<功能>/`，其状态、输入、视图和专属辅助代码放在一起；实际复用的能力再提升到相应公共模块。模块入口只导出调用方需要的类型与操作，网格内部可见性限制在 `pub(in crate::grid)`，窗口内部字段尽量私有，不通过 `#[path]` 绕过目录结构。局部测试随功能放置，窗口协作测试在 `grid/windows/tests.rs`，原生插件适配测试随 `workspace/plugins` 放置，跨库行为测试在 `tests/`；绘制缓存不持有可编辑文档副本。
