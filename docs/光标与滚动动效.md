# 光标与滚动动效

本轮同时落实四项需求：光标动效、紧凑上下布局、字符圆角边框，以及平滑滚动。当前背景为 **84% 不透明度**，覆盖整个客户区且只绘制一次；文字独立保持不透明。

## 光标效果

F6 正向切换，Shift+F6 反向切换。状态栏显示当前效果；切换不会改变文档、光标逻辑位置或已经滚动到的位置。每次启动默认选择“流体”。

| 效果 | 行为 |
| --- | --- |
| 流体 | 四角独立跟随，前沿更快、后沿稍慢，连续换向保留位置和速度 |
| 弹性 | 轻微回弹；平移和形状变化采用带阻尼的连续运动 |
| 余晖 | 较快的角点跟随及短暂渐隐轨迹，最多保留 24 个历史样本 |
| 涟漪 | 较干净的滑动及较大跳转的目标圆环，最多同时保留 6 个圆环 |

短水平移动使用约 40ms 的收敛参数；默认流体长跳的前后角采用不同参数。参数是数学模型的调节量，不能解释为实测的输入到屏幕延迟。

参考了 [Neovide 的光标配置](https://neovide.dev/configuration.html#cursor-settings)、[四角渲染实现](https://github.com/neovide/neovide/blob/main/src/renderer/cursor_renderer/mod.rs)及[弹簧动画实现](https://github.com/neovide/neovide/blob/main/src/renderer/animation_utils.rs)。本次读取的两个源码 blob 分别为 `f3b5be6b0e1de19b911579fcd73b68a43048e553`、`e9a52c36ccf5af43df78824bf78831c4f6b0d24d`；这些是文件 blob 标识，不是 commit SHA。Nanobug 使用自己的 Rust 状态模型和 GPUI 绘制，没有引入 Neovim 核心。

## 对旧动效的可重复诊断

先把旧矩形插值提取到生产代码实际调用的时间模型，再运行 `cargo test --offline --test animation`。三个初始测试均失败：

- 固定 60Hz、每帧前 1ms 到达一个新目标的场景中，旧模型前沿滞后 198.61px。更新目标重置了上一帧计时，丢掉了这段已过时间。
- 一次 200px 跳转在 50ms 时，前后沿进度都是 0.760，没有形变跟随。
- 10px 的短步移动在 40ms 时仍未达到测试要求的 0.5px 以内误差。

修复后这三项均通过。模型在接收新目标前先推进旧状态，保留速度，按四角方向分配收敛参数；原生层使用抗锯齿路径绘制。连续换向时取凸轮廓，避免四角交叉造成错误填充。光标形变、余晖和圆环都保留有限生命周期，结束后不再主动请求帧。

这些是确定性的动效行为测试，不是完整编辑器 FPS 或端到端输入延迟测量。“是否足够丝滑”仍可通过 F6 在实际窗口中比较。

## 滚动与网格布局

- 编辑区与文件管理器分别保留连续的可视行位置和整数目标行。
- 只有正文视图参与分数行位移；圆角字符边框、标题和项目根路径保持固定。
- 动画结束时精确归位到整数行，保证首尾字符行完整显示；动画过程中的正文在区域边界内裁剪。
- 每个区域多缓存一行用于过渡；分数行更新复用已有文字布局和视图缓存，只有首行发生变化才更新正文行数据。
- 光标随所属正文一起平移，避免滚动坐标变化再次触发一遍光标缓动。输入法锚点使用逻辑位置和当前可视坐标。
- 顶部一行、底部两行，外侧纵向留白缩至 5px。内部窗口使用 `╭─╮╰─╯` 字符圆角。

## 验证与交付

- 25 项测试通过：16 项原有文本/文件测试，9 项动画与滚动测试。
- 动画测试包括 60/144/240Hz 同时刻结果一致、连续换向、形状切换、特效历史边界、长时间间隔后的停止、视口平移及整数行停靠。
- `cargo clippy --offline --all-targets -- -D warnings`、格式检查和 Release 构建通过。
- Windows 原生窗口验证了四种效果、滚动后点击定位、切换效果保留视口，以及两个区域各自的平滑滚动和完整行停靠。
- 200 行文本样本滚动后显示第 17–55 行；管理器列表滚动后显示 `item-010`–`item-047`。上下行均完整，标题和边框固定。
- 原生运行 stderr 未发现错误。其他平台和不同输入法仍沿用基础框架记录中的验收边界。

程序：`dist/Nanobug.exe`；默认打开本项目：`Start-Nanobug.ps1`。

`test-output/cursor-effects.gif` 是从实际 Rust 模型采样生成的比较制品，不是窗口录屏或原生帧率证明。重建方式：

```powershell
cargo run --offline --example animation_trace
python tools/render_cursor_preview.py test-output/cursor-effects.csv test-output/cursor-effects.gif
```
