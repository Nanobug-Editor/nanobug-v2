# 基础框架验收

> 后续更新：当前背景已调整为 84% 不透明度，并加入圆角字符边框、紧凑布局、四种光标动效和平滑滚动。下文保留首次基础交付记录；最新结果见[光标与滚动动效](光标与滚动动效.md)。

日期：2026-11-06。工程：Nanobug V2。

## 已落实的范围

- GPUI 原生字符网格，一个文件管理器和一个编辑区，启动时打开工作目录中的项目。
- 内部面板只参考 Glass Editor Demo 的字符边框、嵌入式标题和焦点颜色。顶栏与状态信息保留 Nanobug 内容，没有复制 Demo 的徽标、演示按钮和多编辑区布局。
- 最终设置为 **95% 不透明度、约 5% 透明度**。背景由根视图统一绘制一次，避免区域叠加改变不透明度。文字保持独立不透明，Windows 系统模糊材质仍启用。
- 一个全局平滑光标覆盖管理器、编辑正文和命令行；输入及 IME 锚点使用逻辑位置。
- 简易 Vim 状态机由 Rust 实现，没有 Neovim 核心或子进程依赖。具体操作见[使用指南](使用指南.md)。
- 普通/选择模式绕过 IME 接收命令按键；插入、搜索、命令行模式使用原生文本输入。支持 Ctrl+v 粘贴系统剪贴板。

## Windows 原生交互验证

- 不传路径参数，从项目工作目录启动，初始打开该项目及 README。
- 点击正文，在边框和行号区域偏移后正确定位。
- 中文输入法启用时按 `:` 进入命令行，按 `i` 进入插入模式。
- 使用 `:e test-output/style-ui-smoke.txt` 在原编辑区打开新文件。
- 粘贴 `Nanobug 网格窗口验证 🙂`，Ctrl+s 保存；从磁盘读取的 UTF-8 文本与输入一致。
- Ctrl+[ 返回普通模式，Tab 切换到管理器；光标跨区域移动，焦点边框相应切换。
- 鼠标拖动分隔线，两个网格区域同步调整尺寸。
- 从文件管理器再次选择 README，复用已有缓冲区和编辑位置。
- 验证期间最终程序 stderr 日志为空。

这些检查覆盖了本次基础流程，不代表完整 Vim 兼容、所有输入法组合、大文件性能或其他平台效果已经验收。

## 交付

- 程序：`dist/Nanobug.exe`。
- 默认打开本项目：`Start-Nanobug.ps1` 或 `dist/启动 Nanobug.cmd`。
- 重建：`Build.ps1`。为保留运行中窗口的数据，打包时会保留被替换的旧 EXE；旧窗口可继续运行。
